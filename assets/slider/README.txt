HERO SLIDER IMAGES
==================
Place your slider images here.

Required filenames (already linked in index.html):
  boiler.jpg
  substation.jpg
  scada.jpg
  factory.jpg
  datacenter.jpg

To add more slides:
  1. Copy new image here (e.g. office.jpg)
  2. Add one <div class="hero-slide"> block in index.html inside <div class="hero-slider">
  3. Done!

Recommended image size: 1920x1080px or larger, JPG format.
